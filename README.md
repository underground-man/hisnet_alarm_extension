# HISNet 알림봇

한동대학교 포털(HISNet)의 공지사항 게시판을 주기적으로 확인해서, 새 글이 올라오면
데스크톱 알림을 띄워주는 Chrome 확장(Manifest V3)입니다.

개인 학습/개인용 프로젝트로 만들었고, 아직 Chrome 웹스토어에는 올리지 않은 테스트
버전입니다.

## 기능

- 여러 게시판을 동시에 감시 (기본: 일반공지, 장학공지, 대학원공지 — 옵션에서 자유롭게
  추가/삭제 가능)
- 새 글 발견 시 데스크톱 알림, 클릭하면 바로 해당 글로 이동
- 툴바 아이콘에 안 읽은 새 글 개수 배지 표시
- 팝업에서 새 글 목록을 바로 확인하고 클릭해서 이동 가능
- 옵션 페이지에서 로그인 테스트, 마지막 확인 상태 확인 가능
- 확인 주기 설정 (최소 15분, 학교 서버 부담 방지)

## 설치 방법

아직 스토어에 없어서 개발자 모드로 직접 설치해야 합니다.

1. **[dist/hisnet_notifier.zip](dist/hisnet_notifier.zip)** 다운로드 후 압축 해제
2. Chrome 주소창에 `chrome://extensions` 입력
3. 우측 상단 **"개발자 모드"** 켜기
4. **"압축해제된 확장 프로그램을 로드합니다"** 클릭 → 압축 해제한 `hisnet_notifier` 폴더 선택

정상 설치되면 목록에 "HISNet 알림봇" 카드가 생기고, 툴바에 개구리 아이콘이 나타납니다.

## 사용 방법

1. 툴바 아이콘 우클릭 → **"확장 프로그램 옵션"** (또는 아이콘 클릭 → 팝업의 "설정" 링크)
2. 본인 HISNet 아이디/비밀번호 입력 → **"로그인 테스트"**로 정상 로그인되는지 확인
3. 감시할 게시판 목록 확인/추가/삭제
4. 확인 주기(분) 설정 (기본 60분, 최소 15분)
5. **저장**

이후엔 설정한 주기마다 자동으로 새 글을 확인합니다. 툴바 아이콘을 클릭하면:
- 마지막 확인 시각과 상태(정상/오류)
- 아직 안 읽은 새 글 목록 (클릭하면 해당 글로 새 탭 이동)
- 우측 상단 새로고침(⟳) 버튼으로 즉시 확인

아이콘 위 빨간 숫자는 "확인 안 한 새 글 개수"이며, 팝업을 한 번 열어보면 사라집니다.

## 주의사항

- 아이디/비밀번호는 **암호화 없이 본인 브라우저에만** 저장됩니다 (외부 서버로 전송되지
  않고, HISNet 로그인 요청에만 사용됩니다). 브라우저 확장은 구조상 진짜 암호화가
  의미가 없어서(복호화 키를 결국 확장 코드 안에 같이 둬야 함) 평문 저장 방식을
  그대로 씁니다 — 이 컴퓨터 자체의 보안에 유의해주세요.
- 확인 주기를 너무 짧게 설정하면 학교 서버에 부담을 줄 수 있어 최소 15분으로 제한되어
  있습니다.
- 아직 테스트 버전이라 예상 못한 동작이 있을 수 있습니다. 이슈나 피드백은 알려주세요.

## 기술 스택

Vanilla JavaScript, Chrome Extension Manifest V3 (`fetch`, `chrome.storage`,
`chrome.alarms`, `chrome.notifications`).
